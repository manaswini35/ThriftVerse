# ThriftVerse
A full-stack AI-powered thrift marketplace where users can buy, sell, negotiate, and virtually try on second-hand clothing

## Features

- User Authentication
- Seller Approval Workflow
- Product Moderation
- Wishlist & Cart
- Price Negotiation
- Real-time Chat
- Order Management
- Reviews & Ratings
- AI Virtual Try-On

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other
- JWT Authentication
- Cloudinary
- Socket.io
- Razorpay
